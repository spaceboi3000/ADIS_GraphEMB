# Benchmarking Whole-Graph Embedding Methods

This repository contains the implementation, experimental pipeline, and results of a benchmarking study on **whole-graph embedding techniques**.  
The project evaluates both **unsupervised** and **supervised** graph embedding methods on standard real-world datasets, focusing on their **classification performance**, **clustering behavior**, **visual interpretability**, and **robustness to perturbations**.

---

## Project Objective

The goal of this project is to systematically compare representative whole-graph embedding approaches, including:

- **Unsupervised methods** (Graph2Vec, NetLSD)
- **Supervised deep learning models** (Graph Isomorphism Networks – GIN)

The comparison is conducted across multiple benchmark graph datasets following a unified evaluation protocol.  
In particular, the project investigates three main evaluation axes:

- **Performance**, assessed through downstream tasks:
  - *Graph classification*, evaluated using Accuracy, F1-score, and AUC.
  - *Graph clustering*, evaluated using external clustering metrics such as ARI and NMI, as well as qualitative visualization.

- **Scalability**, analyzed by measuring computational efficiency, including:
  - Embedding generation time,
  - Model training time (for supervised methods),
  - Memory consumption across different embedding dimensions.

- **Robustness**, examined via stability analysis:
  - Random structural and attribute perturbations are applied to the input graphs,
  - Changes in the resulting embeddings are quantified,
  - The impact of perturbations on classification and clustering performance is evaluated.

## Repository Structure

Below is an overview of the repository structure and the contents of each directory.

---

### `.vscode/`
Editor-specific configuration files used during development.

---

### `DATASETS/`
Contains the **original benchmark graph datasets** used in the experiments, including datasets from the TUDataset collection (MUTAG, ENZYMES, IMDB-MULTI).

---

### `permuted_DATASETS/`
Contains **perturbed versions of the original datasets**, generated by applying random structural or attribute-level modifications (e.g., edge removal/addition, node feature shuffling).  
These datasets are used for **stability and robustness analysis**.

---

### `embeddings/`
Stores the **graph-level embeddings** produced by each method and configuration (method, dataset, embedding dimension).  
Each file corresponds to one embedding matrix where each row represents a graph.

---

### `permuted_embeddings/`
Stores embeddings recomputed from the **perturbed datasets**.  
These are used to quantify how much the embeddings change under random perturbations.

---

### `results/`
Contains numerical evaluation outputs, including:
- Classification metrics (accuracy, F1-score, AUC) 
- Clustering metrics (ARI)
- Stability scores
- Runtime and memory measurements
- Overall generating embeddings metrics   

---

### `plots/`
Includes all generated plots used in the analysis and report, such as:
- Classification performance plots
- Clustering evaluation figures
- t-SNE and UMAP visualizations
- Embedding dimension vs. performance trade-off plots

---

### `scripts/`
Contains all Python scripts used to:
- Generate embeddings
- Perform classification and clustering
- Apply perturbations
- Compute evaluation metrics
- Produce plots

These scripts define the full experimental pipeline.

---

### `report/`
Contains the project report and associated figures, including detailed analysis and discussion of results.

---

### `README.md`
This file.

---

### `requirements.txt`
Lists all Python dependencies required to reproduce the experiments.

---
