\subsection{Graph2Vec}
Starting with Graph2Vec~\cite{narayanangraph2vec}, this is an unsupervised graph embedding method that learns 
a fixed length vector representation in a way analogous to how Doc2Vec learns embeddings for documents.
So it's core idea is a graph treated like a document and the rooted subgraphs within it (meaning the local neighborhoods around nodes) 
are treated like words. The logic is that if two graphs share similar structural patterns their embeddings 
will be very close in the learned vector space.


% These subgraphs are extracted using the Weisfeiler Lehman (WL) relabeling process and in order to train the skipgram model it is being assigned a unique label for all the rooted subgraphs in the vocabulary.
% So the graph2vec's algorithm first generate those rooted subgraphs around every node in a given graph and then learns embeddings of the given graphs.
The Graph2Vec's algorithm is shown below:

% $D$: maximum WL depth \\

% $e$: number of epochs \\
% $\alpha$: learning rate
% \Ensure 
% Graph embedding matrix $\Phi \in \mathbb{R}^{|\mathcal{G}| \times \delta}$

% \State Initialize $\Phi \sim \mathcal{U}(-0.5/\delta, 0.5/\delta)$
% \For{$epoch = 1$ to $e$}
%     \State Shuffle $\mathcal{G}$
%     \For{each graph $G_i \in \mathcal{G}$}
%         \For{each node $n \in N_i$}
%             \For{$d = 0$ to $D$}
%                 \State $sg \gets \textsc{GetWLSubgraph}(n, G_i, d)$
%                 \State Update $\Phi_i$ using Skip-Gram with learning rate $\alpha$
%             \EndFor
%         \EndFor
%     \EndFor
% \EndFor
% \State \Return $\Phi$
% \end{algorithmic}
% \end{algorithm}
\begin{algorithm}[t]
\footnotesize
\caption{Graph2Vec}
\label{alg:graph2vec}
\begin{algorithmic}[1]
\Require Graph set $\mathcal{G}$, WL depth $D$, dim $\delta$, epochs $e$, lr $\alpha$
\Ensure Graph embeddings $\Phi \in \mathbb{R}^{|\mathcal{G}| \times \delta}$

\State Initialize $\Phi \sim \mathcal{U}(-0.5/\delta, 0.5/\delta)$
\For{$epoch=1$ to $e$}
  \State Shuffle $\mathcal{G}$
  \For{each $G_i \in \mathcal{G}$}
    \For{$d=0$ to $D$}
      \For{each node $n \in G_i$}
        \State $sg \gets \textsc{WLSubgraph}(n,G_i,d)$
        \State Update $\Phi_i$ via Skip-Gram($sg,\alpha$)
      \EndFor
    \EndFor
  \EndFor
\EndFor
\State \Return $\Phi$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[t]
\footnotesize
\caption{WLSubgraph}
\label{alg:getwlsubgraph}
\begin{algorithmic}[1]
\Require Node $n$, graph $G=(N,E,\lambda)$, depth $d$
\Ensure Rooted subgraph label $sg$

\State $sg \gets \lambda(n)$
\For{$i=1$ to $d$}
  \State $sg \gets \text{hash}\big(sg \,\|\, \{\lambda(u): u \in \mathcal{N}(n)\}\big)$
\EndFor
\State \Return $sg$
\end{algorithmic}
\end{algorithm}


So analytically, Graph2Vec first applies the Weisfeiler-Lehman (WL) relabeling process in order to extract rooted subgraphs around each node up to a specified depth $D$ (Algorithm~\ref{alg:getwlsubgraph}).
Then, it creates a vocabulary called \textit{bag of subgraphs} containing all rooted subgraphs. This vocabulary is formed by collecting the multiset of rooted subgraphs obtained across WL iterations for all graphs.
And finally, it employs a skipgram model to learn graph embeddings by maximizing the likelihood of observing the subgraphs within each graph (Algorithm~\ref{alg:graph2vec}).


\subsection{NetLSD}
NetLSD~\cite{tsitsulin2018netlsd} represent a given graph based on the spectrum of the graph Laplacian capturing global stactural information.
Its main idea is that every graph has a Laplacian matrix whose eigenvalues encode important structural information.
Instead of directly using the raw eigenvalues, it summarizes them using diffusion process, specifically the Heat Kernel.


The NetLSD's algorithm is shown below:

% \begin{algorithm}[H]
% \caption{NetLSD (Heat Trace Graph Signature)}
% \label{alg:netlsd}
% \begin{algorithmic}[1]
% \Require Graph $G=(V,E)$
% \Require $T = \{t_1,\dots,t_K\}$: set of time scales (log-spaced)
% \Require $\mathcal{L}$: Laplacian type (\emph{normalized} or \emph{combinatorial})
% \Require $m$: number of eigenvalues to use (optional; $m=|V|$ for exact)
% \Ensure Signature vector $s \in \mathbb{R}^{K}$ (optionally normalized)

% \State Construct adjacency matrix $A$ of $G$ and degree matrix $D$
% \If{$\mathcal{L}$ is normalized}
%     \State $L \gets I - D^{-1/2} A D^{-1/2}$
% \Else
%     \State $L \gets D - A$
% \EndIf

% \State Compute smallest $m$ eigenvalues $\{\lambda_1,\dots,\lambda_m\}$ of $L$
% \For{$k \gets 1$ to $K$}
%     \State $s_k \gets \sum_{i=1}^{m} \exp(-t_k \lambda_i)$ \Comment{heat trace}
% \EndFor

% \State $s \gets \log(s)$ \Comment{optional but common (stabilizes scale)}
% \State $s \gets \textsc{Normalize}(s)$ \Comment{e.g., $s/\|s\|_2$ (optional)}
% \State \Return $s$
% \end{algorithmic}
% \end{algorithm}
\begin{algorithm}[t]
\footnotesize
\caption{NetLSD (Heat Trace Signature)}
\label{alg:netlsd}
\begin{algorithmic}[1]
\Require Graph $G=(V,E)$, times $T=\{t_k\}_{k=1}^K$, Laplacian type $\mathcal{L}$, eigenvalues $m$
\Ensure Graph signature $s \in \mathbb{R}^K$

\State Build adjacency $A$ and degree $D$
\State $L \gets \begin{cases}
I - D^{-1/2}AD^{-1/2}, & \mathcal{L}=\text{norm} \\
D-A, & \mathcal{L}=\text{comb}
\end{cases}$

\State Compute smallest $m$ eigenvalues $\{\lambda_i\}_{i=1}^m$ of $L$
\For{$k=1$ to $K$}
  \State $s_k \gets \sum_{i=1}^m e^{-t_k\lambda_i}$
\EndFor
\State $s \gets \log(s)$ \Comment{optional}
\State $s \gets \textsc{Normalize}(s)$ \Comment{optional}
\State \Return $s$
\end{algorithmic}
\end{algorithm}


The key advantage of this method lies in its permutation invariance and scalability as we will explore and confirm later..
To improve computational efficiency, it approximates the Laplacian eigenvalue distribution using stochastic trace estimation and so it avoids full eigendecomposition.
This hepls NetLSD to maintain stable performace even for large graphs. 

\subsection{GIN}
The Graph Isomorphism Network (GIN)~\cite{xu2019gin}, known as a supervised graph neural network, is designed to maximize discriminative power among GNNs.
GIN's node representation are updated by aggregating context from neighbor nodes.
At each layer, node features are updated using a sum aggregation function followed by a multilayer perceptron (MLP), 
allowing the model to distinguish different graph structures effectively as shown in Algorithm~\ref{alg:gin_forward}.
Node embeddings are then aggregated using a global pooling operation to produce a graph representation. 
This representation is then passed to a classifier and trained end-to-end using labeled data as shown in Algorithm~\ref{alg:gin_train}.

In contrast to unsupervised methods, GIN learns task specific embeddings optimized directly for classification accuracy. 
While this leads to great performances, it requires labeled datasets (which is difficult to obtain) 
and needs higher computational cost because it's iterative training.

It's algorithm is shown below:

\begin{algorithm}[t]
\footnotesize
\caption{GIN Forward Pass}
\label{alg:gin_forward}
\begin{algorithmic}[1]
\Require Graph $G=(V,E)$, node features $\{h_v^{(0)}\}$, layers $L$
\Ensure Graph embedding $z_G$

\For{$k=1$ to $L$}
  \ForAll{$v \in V$}
    \State $h_v^{(k)} \gets \textsc{MLP}^{(k)}\!\Big((1+\epsilon^{(k)})h_v^{(k-1)}
    + \sum_{u\in\mathcal{N}(v)} h_u^{(k-1)}\Big)$
  \EndFor
\EndFor
\State $z_G \gets \textsc{READOUT}(\{h_v^{(L)}\})$
\State \Return $z_G$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[t]
\footnotesize
\caption{Training GIN}
\label{alg:gin_train}
\begin{algorithmic}[1]
\Require Dataset $\mathcal{D}$, epochs $E$, lr $\alpha$, batch size $B$
\Ensure Trained parameters $\Theta$

\State Initialize $\Theta$
\For{$epoch=1$ to $E$}
  \For{mini-batch $\mathcal{B}\subset\mathcal{D}$}
    \ForAll{$(G,y)\in\mathcal{B}$}
      \State $z_G \gets \textsc{GINForward}(G)$
      \State $\hat y \gets \textsc{Classifier}(z_G)$
    \EndFor
    \State $\mathcal{L}\!\gets\!\frac{1}{|\mathcal{B}|}\!\sum\ell(\hat y,y)$
    \State Update $\Theta$ (e.g., Adam)
  \EndFor
\EndFor
\State \Return $\Theta$
\end{algorithmic}
\end{algorithm}
