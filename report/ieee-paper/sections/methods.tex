\subsection{Graph2Vec}
Graph2Vec, inspired by document representation techniques in natural language processing, 
represents each graph as a set of rooted subgraphs, which are treated like words are in a document. 
These subgraphs are extracted using the Weisfeiler Lehman (WL) relabeling process and in order to train the skipgram model it is being assigned a unique label for all the rooted subgraphs in the vocabulary.
So the graph2vec's algorithm first generate those rooted subgraphs around every node in a given graph and then learns embeddings of the given graphs[CITE].
The Graph2Vec's algorithm is shown below:

\begin{algorithm}[H]
\caption{Graph2Vec}
\label{alg:graph2vec}
\begin{algorithmic}[1]
\Require 
$\mathcal{G} = \{G_1, G_2, \dots, G_{|\mathcal{G}|}\}$: set of graphs, where each $G_i = (N_i, E_i, \lambda_i)$ \\
$D$: maximum WL depth \\
$\delta$: embedding dimension \\
$e$: number of epochs \\
$\alpha$: learning rate
\Ensure 
Graph embedding matrix $\Phi \in \mathbb{R}^{|\mathcal{G}| \times \delta}$

\State Initialize $\Phi \sim \mathcal{U}(-0.5/\delta, 0.5/\delta)$
\For{$epoch = 1$ to $e$}
    \State Shuffle $\mathcal{G}$
    \For{each graph $G_i \in \mathcal{G}$}
        \For{each node $n \in N_i$}
            \For{$d = 0$ to $D$}
                \State $sg \gets \textsc{GetWLSubgraph}(n, G_i, d)$
                \State Update $\Phi_i$ using Skip-Gram with learning rate $\alpha$
            \EndFor
        \EndFor
    \EndFor
\EndFor
\State \Return $\Phi$
\end{algorithmic}
\end{algorithm}


\begin{algorithm}[H]
\caption{GetWLSubgraph}
\label{alg:getwlsubgraph}
\begin{algorithmic}[1]
\Require 
$n$: root node \\
$G = (N, E, \lambda)$: input graph \\
$d$: WL iteration depth
\Ensure 
Rooted subgraph label $sg$

\State $sg \gets \lambda(n)$
\For{$i = 1$ to $d$}
    \State Collect multiset of neighbor labels of $n$
    \State Concatenate and hash labels
    \State Update $sg$
\EndFor
\State \Return $sg$
\end{algorithmic}
\end{algorithm}

For each graph, the multiset of rooted subgraphs obtained across WL iterations forms a \textit{bagof subgraphs}  representation, analoguus to bag of words.
Graph2Vec then employs a skipgram model with negative sampling to learn a vector representation for each graph by maximizing the likelihood of observing its constituent subgraphs.
So, graphs sharing similar local structural patterns are embedded closer in the learned representation space.
Graph2Vec doesn't require node attributes and is fully unsupervised, making it suitable for datasets with limited or noisy labels.

\subsection{NetLSD}
NetLSD represent a given graph using heat kernel signatures derived from the Laplacian Spectrum.
Specifically, it computes a graph descriptor based on the trace of the heat kernel at different time scales and  
manages to capture both local and global structural properties. The NetLSD's algorithm is shown below:


\begin{algorithm}[H]
\caption{NetLSD (Heat Trace Graph Signature)}
\label{alg:netlsd}
\begin{algorithmic}[1]
\Require Graph $G=(V,E)$
\Require $T = \{t_1,\dots,t_K\}$: set of time scales (log-spaced)
\Require $\mathcal{L}$: Laplacian type (\emph{normalized} or \emph{combinatorial})
\Require $m$: number of eigenvalues to use (optional; $m=|V|$ for exact)
\Ensure Signature vector $s \in \mathbb{R}^{K}$ (optionally normalized)

\State Construct adjacency matrix $A$ of $G$ and degree matrix $D$
\If{$\mathcal{L}$ is normalized}
    \State $L \gets I - D^{-1/2} A D^{-1/2}$
\Else
    \State $L \gets D - A$
\EndIf

\State Compute smallest $m$ eigenvalues $\{\lambda_1,\dots,\lambda_m\}$ of $L$
\For{$k \gets 1$ to $K$}
    \State $s_k \gets \sum_{i=1}^{m} \exp(-t_k \lambda_i)$ \Comment{heat trace}
\EndFor

\State $s \gets \log(s)$ \Comment{optional but common (stabilizes scale)}
\State $s \gets \textsc{Normalize}(s)$ \Comment{e.g., $s/\|s\|_2$ (optional)}
\State \Return $s$
\end{algorithmic}
\end{algorithm}

The key advantage of this method lies in its permutation invariance and scalability as we will see later.
Instead of relying on explicit node mappings or subgraph enumeration, NetLSD creates a summary of graph's structure
through spectral descriptors that are known to be robust in small structural variations.
To improve computational efficiency, it approximates the Laplacian eigenvalue distribution using stochastic trace estimation and so it avoids full eigendecomposition.
This hepls NetLSD to maintain stable performace even for large graphs. 

\subsection{GIN}
The Graph Isomorphism Network (GIN), known as a supervised graph neural network, is designed to maximize discriminative power among GNNs [CITE].
GIN's node representation are updated by aggregating context from neighbor nodes.
At each layer, node features are updated using a sum aggregation function followed by a multilayer perceptron (MLP), 
allowing the model to distinguish different graph structures effectively as shown in Algorithm~\ref{alg:gin_forward}.
Node embeddings are then aggregated using a global pooling operation to produce a graph representation. 
This representation is then passed to a classifier and trained end-to-end using labeled data as shown in Algorithm~\ref{alg:gin_train}.

In contrast to unsupervised methods, GIN learns task specific embeddings optimized directly for classification accuracy. 
While this leads to great performance, it requires labeled datasets, which is difficult to obtain, and needs higher computational cost due to iterative training.

\begin{algorithm}[H]
\caption{GIN Forward Pass (Graph Embedding)}
\label{alg:gin_forward}
\begin{algorithmic}[1]
\Require Graph $G=(V,E)$, node features $\{h_v^{(0)}\}_{v\in V}$
\Require $L$: number of GIN layers
\Require $\{\epsilon^{(k)}\}_{k=1}^{L}$: learnable or fixed scalars
\Require $\{\textsc{MLP}^{(k)}\}_{k=1}^{L}$: layer-wise MLPs
\Require \textsc{READOUT}: permutation-invariant pooling (sum/mean/max)
\Ensure Graph embedding $z_G$

\For{$k \gets 1$ to $L$}
    \ForAll{$v \in V$}
        \State $m_v^{(k)} \gets \sum_{u \in \mathcal{N}(v)} h_u^{(k-1)}$
        \State $h_v^{(k)} \gets \textsc{MLP}^{(k)}\!\Big((1+\epsilon^{(k)})\,h_v^{(k-1)} + m_v^{(k)}\Big)$
    \EndFor
\EndFor

\State $z_G \gets \textsc{READOUT}\big(\{h_v^{(L)}\}_{v\in V}\big)$
\State \Return $z_G$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Training a GIN for Graph Classification}
\label{alg:gin_train}
\begin{algorithmic}[1]
\Require Dataset $\mathcal{D}=\{(G_i,y_i)\}_{i=1}^{N}$
\Require $L$: number of layers, epochs $E$, learning rate $\alpha$, batch size $B$
\Require Loss function $\ell(\cdot,\cdot)$ (e.g., cross-entropy)
\Ensure Trained parameters $\Theta$ of GIN + classifier

\State Initialize model parameters $\Theta$
\For{$epoch \gets 1$ to $E$}
    \State Shuffle $\mathcal{D}$
    \For{each mini-batch $\mathcal{B} \subset \mathcal{D}$ of size $B$}
        \ForAll{$(G,y) \in \mathcal{B}$}
            \State $z_G \gets \textsc{GINForward}(G)$ \Comment{Alg.~\ref{alg:gin_forward}}
            \State $\hat{y} \gets \textsc{Classifier}(z_G)$
        \EndFor
        \State $\mathcal{L} \gets \frac{1}{|\mathcal{B}|}\sum_{(G,y)\in\mathcal{B}} \ell(\hat{y},y)$
        \State Update $\Theta \gets \Theta - \alpha \nabla_{\Theta}\mathcal{L}$ \Comment{e.g., Adam}
    \EndFor
\EndFor
\State \Return $\Theta$
\end{algorithmic}
\end{algorithm}
